# 文档索引

给三种不同的读者，三份文档各管一段。改代码前先读对应的那份。

| 文档 | 回答什么问题 | 读者 |
|---|---|---|
| [PRD.md](PRD.md) | **做什么、为什么这么做**。取舍、数据模型、输出契约、成功指标 | 想理解设计意图，或要推翻某个决定的人 |
| [DEVELOPMENT.md](DEVELOPMENT.md) | **怎么改**。环境、命令、模块职责、不能改坏的约定、本机踩过的坑 | 要动手写代码的人（包括未来的自己） |
| [VERIFICATION.md](VERIFICATION.md) | **现在确定能跑吗**。验证过什么、怎么复现、什么还没验证 | 要判断"能不能用"，或接手继续做的人 |

`evidence/` 下是端到端驱动真实窗口留下的截图，VERIFICATION.md 会引用它们。
