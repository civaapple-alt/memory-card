# 文档索引

按读者和任务分工。普通使用者从根目录 README 开始；改代码前读开发指南。

| 文档 | 回答什么问题 | 读者 |
|---|---|---|
| [../README.md](../README.md) | **怎么安装和使用**。快速开始、功能说明、常见操作 | 使用者、首次接触项目的人 |
| [PRD.md](PRD.md) | **做什么、为什么这么做**。取舍、数据模型、输出契约、成功指标 | 想理解设计意图，或要推翻某个决定的人 |
| [DEVELOPMENT.md](DEVELOPMENT.md) | **怎么改**。环境、命令、模块职责、不能改坏的约定、本机踩过的坑 | 要动手写代码的人（包括未来的自己） |
| [VERIFICATION.md](VERIFICATION.md) | **现在确定能跑吗**。验证过什么、怎么复现、什么还没验证 | 要判断"能不能用"，或接手继续做的人 |
| [../LICENSE](../LICENSE) | **使用、修改和分发代码的许可** | 使用者、贡献者、再分发者 |

`evidence/` 下是端到端驱动真实窗口留下的截图，VERIFICATION.md 会引用它们。

## 一句话现状

v0.1.2 正在通过 GitHub Actions 准备 Windows 与 macOS universal 发行包。词与补充句子分开输入，支持拖拽取词、领域释义、入卡、SM-2 复习、历史记录，以及查询停止和可配置超时。查词后可按 Enter 执行主操作；完整句子拆解、托盘图标、到期通知和释义手工编辑仍未实现，详见 [README](../README.md) 与 [VERIFICATION.md](VERIFICATION.md)。
